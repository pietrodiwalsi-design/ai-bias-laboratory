# AI Bias Laboratory

**EU AI Act compliance • Synthetic bias testing • Fairness benchmarking • Mitigation simulation**

A professional-grade platform for AI developers, auditors, and compliance teams to detect, measure, and mitigate bias in AI systems while generating regulatory-ready documentation.

---

## Features (Planned)

### Phase 1 (MVP)
- Synthetic bias injection across 5 protected attributes
- Standardized benchmarks: BBQ, CrowS-Pairs, WinoBias
- Automated fairness metrics (statistical parity, equalized odds, disparate impact)
- Streamlit-based rapid iteration UI
- Reproducible experiments with full configuration logging

### Phase 2
- Visual bias propagation tracking
- Side-by-side mitigation technique comparison (4 methods)
- EU AI Act automated risk classification
- GDPR-compliant data handling

### Phase 3
- PDF/JSON audit report generation
- LIME/SHAP explainability
- GPAI adversarial red-teaming
- Algorithmic Impact Assessment workflow
